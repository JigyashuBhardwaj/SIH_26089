# features/user/

User-flow feature logic used by the `(user)` route group: booking
creation form state, service search/filter (predefined services only),
booking summary assembly, ongoing-request tracking, rating/review
submission. Calls into `../../shared/booking` for rules and `../../services`
for API access — it does not talk to the network directly.

Built in Phase 3 (User App). Empty for now.
