# admin/

The federation/association Admin Dashboard — a separate web application
(not part of the `mobile/` Expo project). It imports domain logic and
types from `../shared` the same way `mobile/` does.

Responsibilities (Phase 5): worker verification, worker profiles/skills/
availability/leaves, incoming booking request queue, worker assignment
and reassignment, request status monitoring, and (secondary/demo) demand
forecasting.

Not started yet — no framework choice has been made. This is a deliberate
decision, not an oversight; it will be picked explicitly before Phase 5
begins.
